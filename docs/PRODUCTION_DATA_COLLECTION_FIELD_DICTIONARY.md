# Production Data Collection Field Dictionary

## Use

This is the canonical Task 240 field contract for the future Clean Eats workbook and Tasks 241-243. It defines collection semantics, not a database schema. All identifiers are staff-friendly transition keys; no staff-entered UUID is allowed. Example values describe format only and are not Clean Eats data.

## Common Fields On Every Record Dataset

These fields apply to every data row in Item Register, Formula Headers/Lines, Methods/Steps, Work Instructions, Area & Applicability, Yield & Batch Rules, Packaging Context, QA Links, Equipment & Resources and Exceptions & Questions.
