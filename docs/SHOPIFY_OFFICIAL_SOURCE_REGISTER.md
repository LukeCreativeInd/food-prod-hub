## Recorded Ambiguities

- The current webhook troubleshooting page contains inconsistent wording about the period after which repeatedly failing subscriptions are removed. The current official changelog states eight retries over four hours. Task 233 must recheck the then-current policy and must not depend on a precise removal window for correctness.
- `latest` GraphQL object pages are discovery references only. Task 233 must select and contract-test an explicitly pinned stable version before using any field or webhook topic.
- Exact webhook topics, access-scope requirements and protected-field approvals must be validated against the selected API version and production app configuration. This register does not itself request a scope or create a subscription.
- Legal deletion, retention, processor and notification duties require qualified legal/privacy review; this register records Shopify platform requirements, not legal advice.

## Source Quality Rule

No third-party blog, forum, package documentation or remembered behaviour is authoritative for Task 229 Shopify facts. Future implementation may use official Shopify libraries, but current official Shopify documentation and the selected stable API schema remain the decision sources.

## Behaviour Preserved

This register performs no Shopify API call, app registration, configuration, installation, token exchange, webhook subscription or live-system change.
